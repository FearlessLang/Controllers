Next round of the agentTools work: what is left to do, and what the guest rounds found.

= 1. Manager bug: the window surfaced check is too strict =

src/gui/Window.java checks 2 s after show (Timer(2000,_->checkSurfaced())) that the window is on screen.
On a freshly booted fedora_gnome (GNOME wayland) the manager is the first X11 client: Xwayland starts cold
with it and the window stays minimized past those 2 s. The manager then fails with "The desktop did not show
the Fearless manager window" and deletes its manager folder and every file association, although the desk
is healthy. The next start works.
Fix it so a slow but healthy desk is never taken for a broken one, and add a test that covers a slow first
surfacing. Details: /data/overnight_logs/agent_tools_vms/kind_reset_test_fedora_gnome.txt (local log).

= 2. Recordings on the guest desks =

Every test of test/agentTools but DesktopDragTest has a recording for ubuntu_gnome only, made with the
window of the current ControllersDesign. Record each test on the 12 guest desks, then run the whole
agentTools package once per desk and fix what broke.
StandInTest takes the tray away by switching off the ubuntu-appindicators GNOME extension; each guest desk
needs its own way to take its tray away, or no StandInTest when the desk has no tray to begin with.

= 3. Tests must fail when their actions were not done =

Review every test in test/agentTools: for each action, ask what the test would observe if the action did
nothing, and add a check where the answer is "nothing". The tests compare screen areas with their look at an
earlier step (ManagerTest.look, same, changed: 16 levels of tolerance per channel, pointer moved to the
screen centre before each shot).

= 4. The desk between runs =

A test that fails leaves its windows open. The next test then finds a file manager window open: GNOME Files
opens the next window at an offset, a double click meant for a file lands on the title bar and maximizes the
window, and Files remembers to open maximized. Between runs on ubuntu_gnome: nautilus -q, and
gsettings set org.gnome.nautilus.window-state maximized false.
DesktopDragTest needs the folders test1 and test2 of the files folder shown on the desktop: it passes only
when the files folder is the folder the desktop shows.

= 5. Smaller observations =

- fedora_cosmic: once in three runs the manager restored from the tray drew its content too small inside the
  full window.
- debian_cinnamon: Cinnamon sometimes crashes into its fallback mode dialog at session start.
- debian_gnome_x11: after boot the screen stays black and the first Ctrl+Alt+T is lost until an X client
  (xrandr as the session user) touches the display.
- Dolphin (opensuse_plasma) remembers a taller window after its first normal close.
The per desk facts are in /data/gym/gui_vms_gym.txt; the per round logs in /data/overnight_logs/agent_tools_vms.
