= 2. Tests must fail when their actions were not done =

Several tests pass when a click misses, because they check only files and exit codes:
- WindowCloseTest: never checks the window went away after the close.
- ForgetRunningProjectTest: a missed Become code, Compile or Run click leaves the same files as a hit.
During the guest rounds the agents checked those steps by hand with screenshots; the tests must check them
themselves. OpenFearlessFileTest shows the intended style: it compares a screen area with its look before
the window opened (16 levels of tolerance per channel, pointer moved to the screen centre before each shot,
since the viewer scales some guests and some compositors draw the pointer into the guest image).
Review every test in test/agentTools for the same pattern: for each action, ask what the test would observe
if the action did nothing, and add a check where the answer is "nothing".
A check on console.txt must allow lines the running program adds by itself ("repaint frame(s) lost" on slow
desks): QuitWhileRunningTest ends its check with a [###] hole after the running line.

= 3. Desks with neither tray nor minimization (void_i3) =

With no StatusNotifierWatcher the manager iconifies on close (Tray calls window.iconifyOnClose()). i3 ignores
iconify requests, so on void_i3 the close does nothing visible, and nothing can bring a hidden window back.
Proposal: on a desk with no tray the manager draws its own tray substitute in Swing: a small undecorated
always-on-top window with the Fearless icon sitting in a screen corner. Closing the main window hides it and
shows the corner icon; a click on the icon reopens the window; a right click opens the same menu as the tray
icon. This takes full control and behaves the same on every desk with no tray (debian_mate, debian_gnome_x11,
fedora_gnome, void_i3), so iconifyOnClose may go away.
Open points: which corner (a corner a panel does not cover), whether tiling desks float an undecorated
always-on-top window (i3 floats dialogs and owned windows), and how WindowCloseTest checks it.
